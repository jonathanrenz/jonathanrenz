## Projetos em destaque

### 🛡️ Inspetron
Plataforma corporativa de gestão de segurança do trabalho (SESMT), com três camadas integradas: app mobile offline-first para inspeção de campo, painel web de gestão configurável por empresa e API REST multi-tenant. Cobre todo o ciclo — inspeção, monitoria, tratativa de não conformidades e permissão de trabalho digital.

`Flutter` `Spring Boot 3` `Java 21` `Next.js` `PostgreSQL` `JWT` `Redis`

### 🛒 [Mais Ofertas](https://github.com/jonathanrenz/maisofertas)
Backend que capta ofertas de Amazon e Shopee, gera legendas com IA e publica automaticamente em canal de Telegram e grupo de WhatsApp, monetizando por link de afiliado. Pipeline com deduplicação, fallback determinístico caso a IA falhe e integração com APIs externas (Canopy, Shopee Affiliate).

`Spring Boot 4` `Java 21` `PostgreSQL` `OpenAI API` `Docker`
